# О DamnClick
Простой кликер для игр, поддерживающий профили. Запускается от имени администратора и работает поверх полноэкранных приложений.

# Профили
<img width="567" height="846" alt="изображение" src="https://github.com/user-attachments/assets/065c358a-393c-4bdd-8346-8bb591d8e293" />

Все профили и данные приложения по умолчанию хранятся в profiles.dat, который должен находиться рядом с exe-файлом. Если profiles.dat нет рядом, то автоматически будет создан новый.

Все бинды находятся внутри профилей. Одновременно может быть активен только один профиль со своим множеством биндов.

Профиль выбирается нажатием по нему, для перехода к биндам профиля нужно нажать на кнопку "➤".
Для удаления профиля необходимо нажать кнопку "🗑️" - она станет красной и после повтороного нажатия по ней профиль будет удалён.

Профили также можно переименовывать, экспортировать и импортировать - в таком случае передана будет информация только о конкретном профиле, а не о всех профилях, как если делиться profiles.dat.

В меню профилей также есть кнопки с краткой сводкой информации по использованию приложения и настройками.

# Настройки
<img width="573" height="846" alt="изображение" src="https://github.com/user-attachments/assets/e7753dfd-6b7d-4944-a810-aff366cba59a" />

В настройках можно:
- Выбрать язык (на данный момент русский/english)
- Задать основной цвет приложению
- Установить громкость уведомлений о вкл/выкл кликера
- Задать путь, по которому будет храниться profiles.dat
- Указать, должно ли приложение сворачиваться в трей при закрытии
- Показывать статус бар внутри приложения:

# Бинды
<img width="572" height="846" alt="изображение" src="https://github.com/user-attachments/assets/e0c88edf-a0ad-462b-9a64-dae64b988eea" />

Бинды внутри профиля отображаются в виде списка и могут быть включены или выключены с помощью ползунка слева. Осторожно, кнопка удаления сразу удаляет бинд, а не после повторного нажатия, как в случае с профилями!

Основные параметры бинда показываются сразу:
- Кнопка активации - кнопка, после нажатия на которую кликер будет активирован
- Кнопка клика - кнопка, которая будет кликаться после активации
- Режим кликера

Существуют 3 режима кликера:
- Удерживать (Hold) - кликает при удержании кнопки активации
- Переключить (Toggle) - кликает после нажатия кнопки активации и до момента, пока она не будет нажата повторно
- Комбо (Combo) - кнока активации переключает в режим ожидания, удержание кнопки клика в котором заставляет кликер работать, пока она не будет отпущена

Для более детальных настроек нужно нажать на кнопку "⚙️".

### Продвинутые настройки
<img width="510" height="725" alt="изображение" src="https://github.com/user-attachments/assets/ca35087e-644c-4017-b715-0695d6f6e34c" />

CPS - кол-во кликов в секунду, которое будет производить кликер. Ползунком лимиты 1-150, но в поле для ввода можно ввести значения выше.

Лимит кликов - кол-во кликов, дойдя до которого кликер должен останавливаться.

Случайность - делает интервалы между кликами случайными, но в сумме за секунду будет выходить целевой CPS. %, на который может измениться интервал между двумя кликами, считается относительно стандартного интервала для заданного CPS (сек/CPS). Этот параметр может помочь избежать обнаружения использования кликера.

Длительность нажатия - делает длительность зажатия кнопки при кликах случайной, работает по аналогии с параметром "Случайность". Также может помочь избежать обнаружения кликера.

Задержка - через какое время (в милисекундах) после нажатия кнопки активации (или нажатия кнопки клика в случае режим "Комбо") кликер должен начать работать. Ползунок на 1-1000, но вписать можно другие значения.
